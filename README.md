# LogiGest - Sistema de Gerenciamento Logístico

Projeto desenvolvido para a disciplina Fundamentos de Programação para Internet - UNIPAR.

## Tecnologias utilizadas
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap
- XAMPP

## Funcionalidades
- Cadastro de produtos
- Cadastro de endereços
- Cadastro de transportadores
- Geração de fretes com múltiplos produtos
- Relatórios de fretes por data

## Como executar
1. Instale o XAMPP.
2. Coloque a pasta do projeto em htdocs.
3. Inicie Apache e MySQL.
4. Importe database/schema.sql pelo phpMyAdmin.
5. Acesse http://localhost/sistema_gerenciamento_logistico/
